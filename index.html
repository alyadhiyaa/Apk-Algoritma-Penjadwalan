Panduan Penggunaan

Pelajari konsep dasar dan langkah menggunakan CPU Scheduler.

Apa itu CPU Scheduling?

CPU Scheduling adalah proses penentuan proses mana yang memperoleh kesempatan menggunakan CPU. Tujuannya mengatur eksekusi proses secara efisien dan membantu mengukur waktu tunggu maupun waktu penyelesaian.

Priority Scheduling

Priority Scheduling pada aplikasi ini menggunakan metode Non-Preemptive. Dari proses yang sudah tiba dan menunggu, CPU memilih proses dengan angka prioritas paling kecil. Setelah dimulai, proses berjalan sampai selesai.

Shortest Remaining Time First (SRTF)

SRTF merupakan versi preemptive dari Shortest Job First. CPU memilih proses dengan sisa Burst Time paling kecil. Jika proses baru datang dan memiliki sisa waktu lebih singkat, CPU dapat beralih ke proses tersebut.

Rumus perhitungan

Turnaround TimeTAT = CT − AT
Waiting TimeWT = TAT − BT
Response TimeRT = First Start − AT

CT adalah Completion Time, AT adalah Arrival Time, BT adalah Burst Time, dan First Start adalah waktu pertama proses mulai dieksekusi.

Langkah penggunaan

  1. Masukkan data proses. Buka Priority Scheduling, lalu isi PID, Arrival Time, Burst Time, dan Priority.
  2. Kelola data. Gunakan tombol edit atau hapus untuk memperbaiki data. Tombol Data contoh dapat mengisi beberapa proses otomatis.
  3. Jalankan simulasi. Tekan Hitung Priority atau Hitung SRTF pada halaman algoritma.
  4. Baca hasil. Periksa tabel metrik, Gantt Chart, dan nilai rata-rata.
  5. Bandingkan. Buka menu Perbandingan untuk melihat hasil kedua algoritma.

Cara membaca Gantt Chart

Setiap blok menunjukkan proses yang menggunakan CPU. Angka di bawah blok menunjukkan waktu mulai dan waktu selesai.
